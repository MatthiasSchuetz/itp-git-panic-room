# Branchstrategie
## Namensschema
- Name des Hauptbranches: main
- Name Feature Branches: \<Nachname\>_\<Feature\>
- Erkennung wo gearbeitet wird: Es darf immer nur eine Person pro Branch arbeiten(ausnahmen mit dem Team abklären)

## Arbeiten mit Branches
- darf auf Main gearbeitet werden: Ja wenn es nicht zu komplex ist (Bei zu hoher Komplexität kann es leichter zu Fehlern kommen)
- wann wird ein neuer Branch erstellt: Komplexere Arbeiten (Um bei Fehlern den Main Branch nicht zu zerstören)
- wann wird ein Branch gelöscht: Nie (Es könnte jederzeit sein dass man ihn wieder braucht für z.B. ein Update eines Features)
